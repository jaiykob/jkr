# Photos go here

Drop photos in this folder, then run `npm run build`. The build writes the
sizes the site serves into `images/photos/` (480, 960 and 1440 pixels wide,
WebP and JPEG, never larger than the original). Use a file name that says
what is in it: `garage-cleanout-after.jpg`.

## For now: stock photos (founder, 2026-10-12)

"good pictures like the one from loadup that show people moving furniture in
the right spots". Until we have photos of our own jobs, the hero, the five size
cards and the service pages use free stock photos (Pexels and Unsplash
licenses: free for commercial use, no attribution required). Every one is
listed in `CREDITS.md`. They show people who are not our crew, so never say
they are; replace them with real job photos as soon as there are some (same
file name, run `npm run build`).

## Our own photos

Only photos of our own jobs, with the customer's permission, and never one
that shows a house number, a plate or a customer's face.
