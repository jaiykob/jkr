# Photos go here

Drop real photos in this folder (a garage before and after, the truck, a
loaded haul; phone photos are fine), then run `npm run build`. The build
writes the sizes the site serves into `images/photos/` (480, 960 and 1440
pixels wide, WebP and JPEG). Use a file name that says what is in it:
`garage-cleanout-after.jpg`.

Only use photos of our own jobs, with the customer's permission, and never
one that shows a house number or a face.
