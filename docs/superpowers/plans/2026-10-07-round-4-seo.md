# Round 4: SEO Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything Google, Bing and AI answer engines read, generated and
checked: sitemap, robots, llms.txt, truthful JSON-LD on every page, share
cards, a one command domain switch, and the launch probes, each useful today
in a local mode.

**Architecture:** `site.config.mjs` holds the site address (and name, phone)
for every generator. `build-towns` owns town and hub JSON-LD (Service with
offers, FAQPage) and share image tags; `build-faq-jsonld` derives FAQPage
only for hand written pages (homepage inside its CITY head, FAQ page).
`build-sitemap`, `build-og-cards` (sharp), `build-images` (sharp) and
`check-schema` / `check-indexability` run in `npm run build` / `npm test`.
`set-domain`, `status`, `indexnow`, `set-gsc-token` are founder commands.

**Spec:** `docs/superpowers/specs/2026-10-07-scoops-import-design.md` (Round 4).

## Global Constraints

- Structured data says only what the page and `pricing.config.mjs` say; prices in schema are real load prices plus real travel fees.
- Nothing in `api/**` changes except reading the site address, with tests.
- Copy rules hold for anything visible (llms.txt included).
- `sharp` is a devDependency, used by build scripts only; Vercel functions never import it.

## Review Focus

1. **A town spanning zones**: its offers run from the smallest load plus its lowest travel to a full truck plus its highest; `check-schema` proves every schema price is a real load plus travel sum.
2. **A noindex page** (checkout, thanks, 404, dashboard): never in the sitemap.
3. **The domain swap run twice**: idempotent; `--check` finds no mixed hosts.
4. **No domain yet**: `status` and `check-indexability` say so plainly and exit 0, and the local mode still checks the built site.
5. **A town FAQ edited**: its FAQPage JSON-LD follows on the next build (same source).

## Tasks

1. Round 4 scorecard, generation 0.
2. `site.config.mjs`; every generator and the API read the site address from it (or `SITE_ORIGIN`); `set-domain` with `--check` and `--dry-run`.
3. JSON-LD: town and hub Service with offers and FAQPage (build-towns); `build-faq-jsonld` for index and faq.html; `check-schema`.
4. `build-sitemap`, `robots.txt`, `llms.txt`, `check-indexability` (local and live).
5. Share cards (`build-og-cards`) and the image pipeline (`build-images`).
6. `status`, `indexnow` (key file), `set-gsc-token`.
7. Docs, `npm run build:seo`, score to 100, review, merge.
